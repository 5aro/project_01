## 화면 기능

- 다섯 캐릭터 선택, 각 캐릭터의 말투로 실제 AI 응답
- 캐릭터별 대화 기록, 추천 시작 문장
- 응답 대기 및 오류 표시, 실패한 입력 복원
- Enter 전송, Shift + Enter 줄바꿈, 한국어 입력 조합 처리
- 모바일 화면 대응
- ‘새 대화’는 모든 캐릭터의 화면 기록과 세션을 새로 시작합니다.

첫 메시지는 선택한 캐릭터의 정보를 Tavily로 검색하므로 시간이 걸릴 수 있습니다. 이후 검색 결과는 서버 메모리에 보관합니다. 시작 인사와 화면의 짧은 캐릭터 소개는 고정 UI 문구이며, 전송 이후 답변은 원본 대화 체인에서 생성합니다. 실제 메시지 전송은 기존 OpenAI 및 Tavily 사용량을 소비합니다.

페이지를 새로고침하면 새 세션이 시작됩니다. 서버를 종료하면 메모리 기록도 사라집니다. 이 서버는 로컬 개발용이며 사용자 인증이나 영구 저장은 구현하지 않았습니다.

## 빌드

npm run build

`dist/`에 프런트엔드 빌드가 생성됩니다. Python API 서버는 별도로 필요합니다. 배포 시에는 `/api` 프록시와 인증을 별도로 구성해야 합니다.


## 대화종료와 캐릭터 분석

`server.py`는 같은 폴더의 `chat.py`를 사용합니다. 채팅 응답을 한 번 이상 받은 뒤 상단의 **대화종료** 버튼을 누르면, 이번 세션에서 모든 캐릭터와 나눈 사용자 메시지를 분석합니다.

팝업에는 닮은 캐릭터 이미지와 이름, 한 줄 성격 설명, 행운 아이템, 힐링 음식, 잘 맞는 친구, 티격태격할 친구가 표시됩니다. 분석 중에는 입력이 잠기고, 실패하면 재시도할 수 있습니다. 완료 후에는 대화 이어가기 또는 새 대화 시작을 선택할 수 있습니다. 이어가기에서는 기존 세션과 기록을 유지합니다. 추가 메시지에 응답을 받은 뒤 다시 대화종료를 누르면 새 대화까지 분석합니다.

서버 코드가 변경되었으므로 기존 Python 서버를 Ctrl+C로 종료한 다음 다시 실행해야 합니다. React 개발 서버도 실행해 두세요. 첫 분석에는 세계관 음식 및 아이템 검색이 추가되어 시간이 걸릴 수 있습니다.

결과와 대화는 서버 메모리에만 저장됩니다. 서버를 재시작하면 새 대화를 시작해 주세요.
